## Integrated validation

- [ ] Run `npm ci`, `npm run typecheck:engine`, `npm test` and `npm run build`.
- [ ] Verify a clean checkout's rebuilt browser bundles match their committed counterparts (`git diff --exit-code -- main-files/bundle.js main-files/bundle-dev.js main-files/dev-diagnostics.js`).
- [ ] Run the Chromium smoke test and .NET build, publish and HTTP smoke test.
- [ ] Confirm real HTTP tests include exact-size, short, oversized, failed and cancelled transfers and mismatched upload acknowledgement.
- [ ] Test real Cloudflare traffic on desktop and mobile, including Quick mode and partial results.
- [ ] Test the self-hosted server on loopback and, where available, a trusted LAN. Do not interpret loopback throughput as ISP speed.
- [ ] Verify mixed endpoint history, CSV provenance, and screenshot labels; old history must remain unclassified.
- [ ] Verify Pages deployment after integration and check release asset contents, versions and notes before tagging.

CI for individual branches is not evidence for the combined commit. Keep this candidate in draft until combined validation is reviewed. The maintainer decides whether to publish the next version.
